# Hóquei Clube da Mealhada

This website was developed as part of the Web Development course and aims to create a dynamic and responsive platform for **Hóquei Clube da Mealhada**.

## Objective
The website allows users to view the 26/27 season squad, follow the upcoming match, check the championship standings table, and access the full match schedule. It also includes an informational section on registrations, membership fees, and club contacts, as well as a dedicated page for consuming dynamic data through a public API.

## Project Structure
- `index.html`: Main page featuring the squad, next match, standings, CSS animation, and accordion menu.
- `games.html`: Dedicated page for the match schedule.
- `api.html`: Page integrating data fetched via the Fetch API.
- `css/`: Stylesheets organized in a modular and responsive manner.
- `js/`: Scripts for interactivity (accordion, navigation, and API requests).
- `images/`: Club logos, icons, and graphic assets.
